# 🚲 自転車競合店調査 AI (Bike Survey AI)

> **店舗マスター照合 ＆ 4K動画・写真ハイブリッド解析 ➔ Excel自動出力 Webアプリケーション**

自転車小売業におけるメガ売場（500〜700台規模）から小規模店まで、**スマホで撮った「歩き撮り動画」または「店頭写真（複数枚一括）」**から、全車種のメーカー・型番・年式・**税抜価格（本体価格）**・マスター差額・実台数・特記事項・参照元ファイル名をAIが自動抽出し、ワンクリックで会社用Excel（`.xlsx`）を出力するWebツールです。

---

## 🌟 主な特徴

* **写真・動画ハイブリッド両対応（API消費を極小化）**:
  * 手元に動画がない場合でも、スマホで撮った何十枚もの写真をまとめて投入可能。
  * **【API回数節約】** 何枚写真があっても、全画像を1回のリクエストに集約して解析（1日20回枠を浪費しません）。
  * **【二重計上防止】** 角度違い・見切れで同じ車体が複数写真に写っていても、AIが自動で1件に統合します。
* **税抜価格（本体価格）基準の実務設計**:
  * 小売業の実務に合わせて、税抜価格を主軸として表示・集計・Excel出力。
  * 店舗マスターとの差額も「税抜差額（売場税抜 − マスター税抜）」として自動算出。
* **参照元ファイル名・タイムスタンプ自動記録**:
  * 出力される調査結果の「参照元ファイル・時間」列に、該当車両が映っている**実際のファイル名（例: `IMG_20240904_1030.jpg`）**や動画の出現時間を記録。
* **どの端末（スマホ・他PC）からでもキー入力不要で利用可能**:
  * **「📱 端末共有リンク」** 機能により、発行されたURLをスマホや他PCで開くだけで、APIキーが自動保存され初期設定ゼロで即使えます。
* **GitHub Pages 完全無料ホスティング対応**:
  * GitHubにプッシュするだけで、自社専用のWebアプリURLが自動発行されます。

## 🚀 GitHubへの公開・デプロイ手順（初回のみ）

本プロジェクトをGitHubにアップロードして、社内全員が使えるWebアプリURLを発行する手順です。

### STEP 1: GitHubで新規リポジトリを作成
1. [GitHub (https://github.com/)](https://github.com/) にログインします。
2. 画面右上の「＋」➔ **「New repository」** をクリックします。
3. Repository name に `bike-survey-web` と入力します。
4. 公開範囲（**Private** または **Public**）を選択し、「Create repository」をクリックします。
   ※APIキーをGitに含めずにURLパラメータで配る場合は **Public** でも安全に運用可能です。

### STEP 2: ローカルからGitHubへプッシュ
PCのPowerShellで以下のコマンドを実行します：

```bash
cd C:\Users\ctyan\.gemini\antigravity\scratch\bike-survey-web
git remote add origin https://github.com/<あなたのユーザー名>/bike-survey-web.git
git branch -M main
git push -u origin main
```

### STEP 3: GitHub Pages の有効化
1. GitHubのリポジトリ画面上部の **「Settings」** タブをクリックします。
2. 左メニューの **「Pages」** をクリックします。
3. **「Build and deployment」>「Source」** で **「GitHub Actions」** を選択します。
4. 数分待つと、画面上部に専用のURL（例: `https://<あなたのユーザー名>.github.io/bike-survey-web/`）が発行されます！

## 📱 どの端末からでも使えるようにする連携手順（超簡単）

1. PCでWebアプリを開き、右上の **「⚙️（歯車アイコン）」** をクリックします。
2. **「📱 端末共有リンク」** ボタンをクリックします。
   （キー情報を含んだ専用リンクが自動コピーされます）
3. このリンクを、調査スタッフのスマホ（LINEや社内チャット、メール等）に送ります。
4. スタッフがスマホでそのリンクをタップすると、**スマホ側にもキーが自動登録され、次回以降キー入力不要で即使えるようになります！**
